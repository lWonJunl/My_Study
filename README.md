# My Study

프로그래밍 기초, 프론트엔드 개발, 데이터베이스를 공부하며 작성한 예제와 문제 풀이를 기록하는 개인 학습 저장소입니다.

## 학습 내용

| 분야 | 내용 |
| --- | --- |
| C | 기본 입출력, 산술 연산, 조건문, 백준 문제 풀이 |
| Python | 기본 입출력, 조건문, 반복문, 문자열 처리, 백준 문제 풀이 |
| Java | 기본 문법, 배열, 메서드, 클래스와 객체 |
| Frontend | HTML/CSS 기초, JavaScript, DOM 조작, 이벤트와 입력값 처리 |
| Database | SQL 데이터 조회, 조건 검색, 정렬, 추가, 수정, 삭제 |

## 저장소 구조

```text
my-study/
├── Programming/
│   ├── C/          # C 예제 및 백준 문제 풀이
│   ├── Python/     # Python 예제 및 백준 문제 풀이
│   └── Java/       # Java 기초 문법 실습
├── Frontend/       # HTML, CSS, JavaScript 실습
├── Database/
│   └── SQL/        # SQL 기초 실습
└── README.md
```
